Политика конфиденциальности

Действует для приложения MoniTune и этого сайта. Редакция от 30 июля 2026 года.

Коротко

  • Персональные данные не собираются и не передаются.
  • В приложении нет ни телеметрии, ни аналитики использования.
  • Учётные записи и регистрация не используются.
  • Настройки хранятся только на вашем компьютере.
  • Единственное сетевое обращение приложения — проверка обновлений на GitHub. Отключается в настройках.
  • На сайте есть счётчик посещений Google Analytics — он загружается только после вашего согласия. Подробнее.

Что программа хранит локально

Параметры приложения — шаг изменения, значения ночного режима, расписание, состояние переключателей, связка яркости и контраста для каждого монитора — сохраняются в файле настроек в профиле пользователя. Эти данные не покидают компьютер.

Журнал работы приложения пишется в локальный файл и хранится в двух последних версиях (текущая сессия и предыдущая). В журнал попадают технические сведения: модель монитора, интерфейс подключения, коды ошибок обмена данными, версии приложения и системы. Личных данных, содержимого экрана, вводимого текста или списка запущенных программ там нет.

При аварийном завершении приложение сохраняет диагностический отчёт в локальную папку. Автоматическая отправка такого отчёта не выполняется.

Сетевые обращения

Приложение выполняет одно сетевое обращение — проверку наличия новой версии в публичном репозитории проекта на github.com. Проверка происходит при запуске, далее примерно раз в четыре часа и после выхода компьютера из спящего режима. При обнаружении обновления загружается пакет приложения.

При таком обращении GitHub, как владелец сервиса, видит ваш IP-адрес и стандартные заголовки HTTP-запроса — это неизбежное свойство любого обращения к внешнему сайту и регулируется политикой конфиденциальности GitHub. Никакие сведения о вас, вашем компьютере или конфигурации мониторов при этом не передаются.

Проверку обновлений можно отключить: меню иконки → Настройки → Обновления и диагностика → «Автоматически проверять обновления при запуске». После отключения приложение не обращается к сети вообще, пока вы не запросите проверку вручную.

Отправка диагностики

Пункт «Собрать диагностику» в меню иконки создаёт архив на рабочем столе. Архив остаётся на вашем компьютере: вы сами решаете, передавать его разработчику или нет. Содержимое архива описано в документации — журнал работы, состояние мониторов, файл настроек и отчёты об аварийных завершениях.

В настройках есть отдельный переключатель для автоматической отправки отчётов об аварийных завершениях. По умолчанию он выключен, и без указанного адреса приёма отправка не выполняется даже во включённом состоянии.

Взаимодействие с системой и оборудованием

  • Обмен командами с внешними мониторами по локальной шине DDC/CI через системный интерфейс Windows.
  • Управление подсветкой встроенного экрана ноутбука через интерфейс WMI.
  • Получение списка дисплеев и их характеристик через стандартные вызовы Windows.
  • По вашей команде — регистрация в списке автозагрузки Windows.
  • Показ уведомлений об обновлениях через системный сервис уведомлений Windows.

Аналитика и файлы cookie на сайте

Этот раздел относится только к сайту. Приложение MoniTune аналитику не использует — ни при включённом счётчике, ни при выключенном.

На сайте установлен счётчик посещений Google Analytics 4. Он загружается только после вашего явного согласия. Пока вы не нажали «Разрешить» в баннере, скрипт счётчика не подключается: ни одного обращения к серверам Google и ни одной cookie на вашем устройстве не появляется. Отказ запоминается и баннер больше не показывается.

При согласии счётчик получает стандартный для веб-аналитики набор сведений:

  • адреса открытых страниц сайта и переходы между ними;
  • источник перехода — поисковая система, ссылка с другого сайта или прямой заход;
  • тип устройства, браузер, разрешение экрана, язык;
  • страна и город по IP-адресу (сам адрес усечён — передаётся с параметром анонимизации);
  • идентификатор в cookie _ga, по которому повторный визит отличается от нового.

Имя, электронная почта, содержимое экрана, сведения о ваших мониторах и любые данные из приложения счётчику не передаются — он видит только посещения этих веб-страниц. Реклама и ремаркетинг отключены. Обработка на стороне Google регулируется его политикой конфиденциальности.

Решение можно изменить в любой момент — кнопка ниже вернёт баннер выбора.

Кроме счётчика сайт cookie не ставит. Страница статистики загружает публичные данные о выпусках через открытый программный интерфейс GitHub без передачи каких-либо ваших данных.
