MoniTune documentation

MoniTune controls the brightness and contrast of your monitors from the Windows notification area. External monitors are driven via the DDC/CI standard, a laptop's built-in screen via the WMI interface. Below: how it all works, what you can configure, and what to do when a monitor does not respond.

Installation

Download MonitorTune-Setup.exe from the releases page and run it. The installer asks for administrator rights — it needs them to add the signing certificate to the system store and to install the application package.

  1. Importing the signing certificate into the Trusted Root Certification Authorities and Trusted People stores.
  2. Installing the MSIX application package.

The package is self-contained: .NET 9 and the Windows App SDK are already inside, so nothing extra has to be downloaded.

Requirements: Windows 11, or Windows 10 version 2004 (build 19041) and newer, on x64. External monitors need DDC/CI support; for a laptop's built-in screen the stock graphics driver is enough.

Control panel

After installation a sun icon appears in the notification area. Clicking it opens the panel: every monitor gets its own card with sliders and a line describing how it is connected.

How it works

External monitors: DDC/CI

The DDC/CI standard describes a service channel between the graphics card and the monitor. It carries not only display capabilities but also image control commands — the same ones the buttons on the monitor itself trigger. MoniTune uses the standard VCP codes: 0x10 for brightness and 0x12 for contrast.

The channel runs over the ordinary signal cable alongside the video, so no extra hardware or drivers are needed. The app detects the graphics vendor and the connection type in order to pick a safe interval between commands.

Laptop built-in screen: WMI

Built-in panels have no physical DDC/CI channel — the signal never leaves the platform. Windows exposes backlight control through WMI instead, and that is the path MoniTune takes. The WMI standard has no contrast parameter, so a built-in screen's card shows only a brightness slider.

Why the app does not poll monitors in the background

A monitor's controller is slow to process commands. Talking to it too often causes failures: on some models the on-screen menu stops opening, on others the buttons ignore input until the monitor is power-cycled. That is why MoniTune has no periodic polling and keeps a minimum interval between commands sent to the same monitor.

Sync mode

Flip the Sync toggle, and moving any slider will apply to every monitor at the same time. Handy when the light in the room changes and the whole desk needs adjusting.

The other monitors' sliders follow the one you drag. The number on the right shows the value the monitor confirmed — so you can see when a screen did not accept the command.

Linking brightness and contrast

The link button in the top-right corner of a card ties the two parameters of that monitor together: changing brightness changes contrast to the same value. The setting is remembered per monitor.

Night mode

Night mode remembers the current values and then moves the monitors to reduced ones. Turning it off restores the daytime values. You can trigger it with the moon button, a hotkey, or a schedule.

What you can configure:

  • Brightness at night and Contrast at night — the values the monitors move to.
  • Schedule night mode — switch automatically at the times you set.
  • The From … To … interval — the night period; crossing midnight is supported.

Hotkeys act on the monitor the cursor is currently over. If that monitor does not support the parameter — asking a laptop's built-in screen for contrast, for example — the command goes to the first monitor that does support it. The step is set in settings and defaults to 5 percent.

Start with Windows

Start with Windows in the icon menu adds MoniTune to Windows startup. Windows requires confirmation for apps installed outside the Microsoft Store: if the system declines the request, MoniTune shows a notification pointing to the right settings page.

You can check and toggle the startup setting under Settings → Apps → Startup. The checkbox in the MoniTune menu always reflects the real state in the system.

Staying awake

Two independent switches in settings help when the computer has to stay active — during a long task or a presentation, for instance.

  • Keep the computer and display awake — asks the system to keep the machine in an active state.
  • Simulate user activity — a periodic input signal. Keeps your status online in messaging apps. The simulation is invisible by default; a separate option makes it visible — the cursor shifts by one pixel and moves back.

Updates

MoniTune checks the project's public repository for new versions and can update itself. The check runs at startup, then every four hours, and after the computer wakes from sleep. It can be switched off in settings.

What happens during an update:

  1. The description of the latest release is fetched and its Ed25519 signature verified.
  2. The package is downloaded and its SHA-256 checksum compared.
  3. The package's digital signature and the publisher's thumbprint are checked.
  4. The package is installed and the app restarts automatically.

Download progress is shown in a notification. Installing a version older than the current one is blocked. Choosing “Later” in the notification is remembered — that version will not be offered again, though you can still install it from the icon menu.

Diagnostics

Collect diagnostics in the icon menu drops an archive on your desktop with the log, monitor state, settings and crash reports. The archive is never sent anywhere — you decide who receives it.

What is inside:

  • The log of the current and the previous session.
  • The monitor list: connection interface, value scale, capability flags, last error code.
  • The settings file.
  • Up to the ten most recent crash reports.
  • System details: app version, Windows build, architecture, WMI availability.

When something goes wrong

The monitor is listed but the slider does nothing

Check DDC/CI in the monitor's on-screen menu. On some models the option is off by default, on others it is buried in a service section. If the monitor is connected through a DisplayLink adapter, software control is impossible: such adapters do not carry the service channel.

A monitor disappeared from the panel

MoniTune shows the displays Windows reports. Check Win + P — the mode should be Extend or Duplicate, not PC screen only. Under Settings → System → Display both monitors should be active. The list refreshes by itself once the monitor is back; Rescan monitors makes it immediate.

The value jumps back

Most likely HDR or adaptive brightness is active, which means the system owns the backlight. MoniTune recognizes this and labels the monitor accordingly. Turn HDR off in display settings if you need software control.

The monitor's on-screen menu stopped responding

A rare case on certain models: the controller is overloaded with commands. Switch the monitor off with its power button, wait a few seconds, and turn it back on. MoniTune limits the command rate precisely to prevent this.

The icon is hidden in the overflow area

Windows moves the icons of newly installed apps into the hidden area. Click the arrow next to the clock and drag the sun out to the other icons — the position is preserved, even across app updates.

Frequently asked questions

My monitor is missing from the list, or the slider does nothing. What should I do?

An external monitor needs DDC/CI switched on. Open the on-screen menu with the buttons on the monitor itself and find the option — vendors call it DDC/CI or just DDC, and it is sometimes buried in a service section. If there is no such option at all, the monitor does not support software control.

Also use Rescan monitors in the icon menu — the app will report how many displays Windows currently sees.

Does MoniTune work with a laptop's built-in screen?

Yes. Built-in panels have no DDC/CI channel, so brightness is controlled through the Windows WMI interface. That standard has no contrast parameter for built-in screens, so the card for a built-in screen shows only a brightness slider.

Why does the slider react with a slight delay?

A monitor's controller processes DDC/CI commands slowly, and sending them too quickly causes failures — on some models the on-screen menu stops responding. MoniTune deliberately limits the rate: the interval is chosen based on the connection type and the vendor, from 80 ms on HDMI to 300 ms on USB-C.

Will my values survive a reboot?

For external monitors, yes: the values live in the monitor's own memory and survive a power cycle. MoniTune does not restore them at startup, to avoid burdening the controller with unnecessary commands.

Which connections are supported — HDMI, DisplayPort, USB-C?

DDC/CI works over every digital interface: HDMI, DisplayPort, DVI and USB-C in DP Alt Mode. The exception is DisplayLink adapters, which do not pass the service channel through. Stability also depends on the monitor model and on cable quality.

Does MoniTune collect any user data?

The app does not. It has no telemetry and no usage analytics, there are no accounts, and settings stay on your machine. Its only network request is a periodic check for new versions on the public GitHub repository, which can be switched off in settings.

As for the website itself: it runs a Google Analytics visit counter. It loads only after you explicitly agree in the banner, has no effect on the application, and can be turned off at any time. More in the privacy policy.

Brightness will not change while HDR is on. What now?

In HDR mode the system owns the backlight, and the monitor may accept a command without any actual effect. MoniTune detects this and labels the monitor as controlled by the system. Turn HDR off in display settings if you need software control.

Are administrator rights required?

Not to run the app. Rights are needed only by the installer: to add the signing certificate to the system store and install the package.

Why is the installer about 86 MB?

The package is self-contained — .NET 9 and the Windows App SDK are already inside. That way installation completes on a clean Windows install with no prompts for extra components: users previously saw a dialog telling them to install the .NET Runtime.

How do I uninstall MoniTune?

Settings → Apps → Installed apps → MoniTune → Uninstall. The signing certificate remains on the system; you can remove it manually through the certlm.msc snap-in if you need to.

Can I use it on several computers?

Yes, there are no limits. The app is free and the license allows installation on any number of devices, including in a commercial environment. The source is open under the MIT license.
