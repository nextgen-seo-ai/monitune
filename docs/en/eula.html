2. Purpose of the program

MoniTune is a Windows utility that provides control over the brightness and contrast of connected external monitors, as well as the brightness of laptop built-in displays, through an icon in the notification area. External monitors are driven over the standard DDC/CI interface, built-in panels over the WMI interface.
