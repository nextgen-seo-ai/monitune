Privacy policy

Applies to the MoniTune application and to this website. Last revised July 30, 2026.

In short

  • No personal data is collected or transmitted.
  • The application contains neither telemetry nor usage analytics.
  • There are no accounts and no registration.
  • Settings are stored only on your computer.
  • The application's only network request is an update check on GitHub. It can be turned off in settings.
  • The website runs a Google Analytics visit counter that loads only after you agree. Details below.

What the application stores locally

Application parameters — the adjustment step, night mode values, the schedule, the state of the switches, whether brightness and contrast are linked for each monitor — are saved to a settings file in your user profile. This data never leaves the computer.

The application log is written to a local file and kept for the two most recent sessions (the current one and the previous one). It contains technical details: monitor model, connection interface, error codes from the data exchange, application and system versions. The log contains no personal data, no screen content, no typed text and no list of running programs.

If the application crashes, it saves a diagnostic report to a local folder. Such a report is never sent automatically.

Network requests

The application makes a single network request — a check for a new version in the project's public repository on github.com. It runs at startup, then roughly every four hours, and after the computer wakes from sleep. When an update is found, the application package is downloaded.

During such a request GitHub, as the service owner, sees your IP address and the standard HTTP headers — an unavoidable aspect of any request to an external site, and it is governed by GitHub's privacy policy. No information about you, your computer or your monitor configuration is transmitted.

Update checking can be turned off: icon menu → Settings → Updates and diagnostics → “Check for updates on startup”. Once disabled, the application makes no network requests at all until you request a check manually.

Sending diagnostics

Collect diagnostics in the icon menu creates an archive on your desktop. The archive stays on your computer: you decide whether to send it to the developer. Its contents are described in the documentation — the application log, monitor state, the settings file and crash reports.

Settings contain a separate switch for automatic crash report submission. It is off by default, and without a configured receiving address nothing is sent even when it is on.

Interaction with the system and hardware

  • Exchanging commands with external monitors over the local DDC/CI bus through the Windows system interface.
  • Controlling a laptop screen's backlight through the WMI interface.
  • Obtaining the list of displays and their properties through standard Windows calls.
  • At your request — adding the application to the Windows startup list.
  • Showing update notifications through the Windows notification service.

Analytics and cookies on the website

This section concerns the website only. The MoniTune application uses no analytics — neither when the counter is enabled nor when it is disabled.

The website runs a Google Analytics 4 visit counter. It loads only after your explicit consent. Until you press “Allow” in the banner, the counter script is not loaded: not a single request reaches Google's servers and not a single cookie appears on your device. If you decline, that choice is remembered and the banner is not shown again.

If you consent, the counter receives the standard set of information used in web analytics:

  • the addresses of the pages you open and how you move between them;
  • the referral source — a search engine, a link from another site, or a direct visit;
  • device type, browser, screen resolution, language;
  • country and city derived from the IP address (the address itself is truncated — it is sent with the anonymization parameter);
  • an identifier in the _ga cookie that distinguishes a returning visit from a new one.

Your name, email address, screen content, details about your monitors and any data from the application are not passed to the counter — it only sees visits to these web pages. Advertising and remarketing are disabled. Processing by Google is governed by its privacy policy.

You can change your decision at any time — the button below brings the consent banner back.

Apart from that counter the site sets no cookies. The statistics page loads public release data through GitHub's public API without transmitting any of your data.
